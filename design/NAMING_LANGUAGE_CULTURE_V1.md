# Naming & Language Culture v1

Status: PROVISIONAL WORLD / STYLE DESIGN
Project: 《우주선에는 인간이 한 명뿐이다》

---

# 1. Problem

A 600-year generation-ship civilization should not sound like:
- everyone received contemporary Korean names yesterday
- everyone uses fantasy-SF apostrophe names
- eight habitats each speak mutually unintelligible languages for no operational reason

The naming system must balance:
- historical depth
- global-origin plausibility
- Korean reader accessibility
- read-aloud clarity
- habitat cultural variation

---

# 2. Ship Language

## Working model

The ship has one dominant **operational common language** used for:
- education
- inter-habitat administration
- engineering
- emergency communication
- public media

Over centuries it has changed naturally from launch-era language(s), but standardized technical/education systems prevent fragmentation into mutually unintelligible languages.

Habitats still develop:
- accent
- slang
- rhythm
- specialized vocabulary
- honorific habits
- inherited heritage terms

### Reader translation convention

Korean prose renders the common language as natural Korean.

This is a translation convention, not a claim that the entire ship literally speaks 21st-century Korean.

Avoid explaining this in narration unless language becomes plot-relevant.

---

# 3. Heritage Languages

Launch population was culturally plural.

Over six centuries:
- many Earth languages survive in archives, ritual, song, names, specialist communities, family phrases
- a smaller number retain active community speakers
- no single heritage language maps neatly to one habitat

This prevents habitats from becoming “the Korean zone / Arab zone / European zone.”

Cultural mixing is historical and uneven.

---

# 4. Personal Name Structure

Preferred default:

**given/personal name + family/household name**

Legal identity does not depend on immutable family surname.

Adults may:
- retain birth household name
- adopt partner/household name
- use a chosen professional/community name

H4 family culture makes this flexibility especially visible.

Reader-facing use should usually stay simple:
- one given name in dialogue
- full name only when socially/professionally useful

---

# 5. Name Origin

Names remain recognizably descended from Earth names because names are unusually durable cultural artifacts.

Over centuries they undergo:
- shortened pronunciation
- spelling drift
- cross-language borrowing
- reuse detached from original ethnicity/gender

This gives the cast names that sound human rather than fantasy-species-like.

---

# 6. Four Naming Approaches Compared

## A. Contemporary global names unchanged
Examples structurally: contemporary Korean/English/Arabic/Spanish/etc. names.

Strength:
maximum immediate readability.

Risk:
600-year society can feel insufficiently evolved.

Score: 8/10.

## B. Fully invented future names
Strength:
strong temporal distance.

Risk:
read-aloud collisions, fantasy feeling, cognitive overload.

Score: 5/10.

## C. Habitat-specific naming systems
Strength:
strong cultural texture.

Risk:
turns habitats into ethnic theme parks and creates too many rules.

Score: 6.5/10.

## D. Earth-derived names with centuries of drift + flexible household naming
Strength:
readable, historically plausible, culturally layered, compatible with habitat variation.

Risk:
requires disciplined naming rather than gimmicks.

Score: **9.5/10.**

### Preferred
**D**, with selective use of A for some conservative family traditions.

# 7. Habitat Naming Tendencies

These are tendencies, not laws.

## H1 Civic Core
More stable/formal two-part names in professional settings.

## H2 Biosphere Commons
Plant/season/heritage names may be more fashionable, but avoid fantasy nature-name overload.

## H3 Fabrication Concord
Nicknames/professional names common in crews; legal names still ordinary.

## H4 Kinship Belt
Most visible use of flexible household/co-parent family names.

## H5 Exchange Ring
Names from many heritage streams; shortening and cross-language forms common.

## H6 Memory Commons
Some families deliberately preserve older Earth-name spellings/pronunciations.

## H7 Low-Link Communities
Local names and privacy/chosen names more common; no requirement to reveal full civil name socially.

## H8 Legacy Habitat
Older naming fashions survive in pockets, mixed with newer forms.

# 8. Read-Aloud Naming Rules

Core cast names must differ on:
- initial consonant
- first vowel
- syllable count/rhythm where possible

Avoid central combinations like:
- 미라 / 리라 / 니라
- 이안 / 이완
- 서진 / 수진 / 세진
- 레아 / 레나 / 레라

Within the 10 most important characters:
- no more than 2 names begin with same Korean consonant sound if avoidable
- no identical final two syllables
- surnames should not be the main means of distinction

---

# 9. Name Length

Preferred Korean rendering:
- given name: ~2–4 syllables
- family/household name: ~1–3 syllables

Avoid:
- long strings requiring repeated rereading
- apostrophes
- numerals
- technical designation-style personal names

Unless a specific subculture earns an exception.

---

# 10. Gender and Names

Six centuries of cultural mixing means many names are less rigidly gendered than today.

However, do not intentionally make every name ambiguous merely to signal futurism.

Reader clarity comes first.

---

# 11. Family Names and the Theme

Do not over-symbolize naming.

But flexible household names can quietly reinforce:
- family as lived relation
- law recognizing more than genetic descent
- continuity without biological purity

This should appear as ordinary social fact long before the ontology reveal.

---

# 12. Institutional / Faction Names

Reader-facing institutional names should be short and speakable.

Working Korean names should generally be 2–5 syllable chunks plus a familiar category:
- 전환국
- 항해위원회
- 복원권 연맹
- 기원기록회

Exact names remain open.

Avoid alphabet soup.

---

# 13. Core Ontology Terms — Preferred Korean Direction

Current preferred spoken terms:

- seeded development → **시드 발달**
- unseeded development → **비시드 발달**
- cognition seed → **인지 시드**
- developmental provenance → **발달 기원** / **기원 이력**
- continuity capture → **상태 기록** (working)
- restoration → **복원**
- restored claimant/person → **복원자** or **복원 인격** (OPEN)
- Continuity Settlement → **연속성 협약** (preferred working term)

Potential problem:
`시드` is an English loanword, but short and audibly distinct.

Before Freeze, compare with fully Korean alternatives.

---

# 14. Reader-Facing “AI” Rule

Do not call every seeded citizen `AI` in normal narration after the explanation is established.

Use `AI/인공지능` primarily when:
- discussing the historical technical category
- a faction intentionally claims/rejects the label
- a character uses it emotionally/politically

Narration should usually call them people/citizens/characters.

This avoids accidentally dehumanizing the cast through authorial diction.

---

# 15. Naming Freeze Process

Do not choose names one by one ad hoc.

Before final core-name freeze:

1. create 4 complete core-cast name sets
2. pronounce all sets aloud in Korean order
3. check first-syllable collisions
4. check emotional/genre connotations
5. check no other major IP/project uses the same distinctive names
6. select one full set, then adjust only weak entries

This prevents locally good names from becoming globally confusing.

---

# 16. Current Verdict

Preferred world-language model:

**one ship common language + habitat dialect/culture + surviving heritage language fragments + Earth-derived/drifted personal names + flexible household naming.**

This is enough to proceed with character/faction design without freezing exact names yet.
