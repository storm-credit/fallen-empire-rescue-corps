# 1. Naming Requirements

Core names must:
- sound distinct when heard, not only read
- remain easy for Korean web-novel readers
- feel descended from Earth naming traditions without mapping each habitat to an ethnicity
- avoid over-fantasy apostrophe / title-like forms
- avoid symbolic names such as Adam/Eve for BH-1
- keep family relations obvious where useful
- allow 600 years of linguistic drift

Core roles:
- P protagonist
- M mother
- S younger sister
- C colleague
- I former intimate partner
- T mentor
- R rival
- O older H8 memory anchor
- B BH-1 sole baseline human

# 3. Audio Collision Test

## First-syllable collision
None among core nine.

PASS.

## Rhythmic collision
- 하렌 / 오렌 share final `렌` sound.

Potential issue:
They are important protagonist/mentor roles and may appear in same scenes.

### Correction options
Mentor `오렌 다스` can change to:
- **토마 다스**
- **오드 다스**
- **데론 다스**

Preferred correction candidate:
**토마 다스**

Why:
- distinct `토`
- Earth-root feel from Thomas/Toma
- does not collide with 테사

If adopted, first initials remain distinct enough but `테/토` are somewhat close; still better than 하렌/오렌 rhyme.

Alternative:
**세브 다스** gives maximal distinction but more invented feel.

Keep mentor name OPEN until full spoken list test.

# 4. Semantic / Symbolic Check

## 하렌
No intended meaning related to humanity, heroism, or AI.

## 마라
Earth-root name; no deliberate “mother goddess” symbolism.

## 유나
Common Earth-derived name across multiple cultures; useful for cultural blending.

## 테사
Familiar, short, practical.

## 엘린
Familiar but not symbolically loaded.

## 키안
Lightly drifted Earth-root; no “Cain” spelling/meaning should be invoked in-world.

## 브람
Older-generation feel without “wise sage” semantics.

## 나디아
Ordinary recognizable name; important precisely because BH-1 must not be named Eve/Genesis/etc.

# 5. Family/Household Naming Rule Applied

At story start:
- 하렌 / 마라 / 유나 share `사빈` family/household name

This does **not** prove biological lineage alone.

It is their current family-name tradition.

The world permits adults to retain/change household names, but this family retained one stable name.

This subtly supports lived kinship without requiring a lecture.
