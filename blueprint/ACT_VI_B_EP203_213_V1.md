# EP205 — A Backup Is Not a Rescue Team

**Immediate Goal**
Determine what operational risk the capture requirement actually mitigates and what it does not.

**Primary Engine**
E5 Operational Resilience.

**Secondary**
E2/E7.

**External Event**
Tessa/Elin/labor planners separate two risks:

### Immediate mission safety
A dead/incapacitated specialist cannot be restored quickly enough to rescue today's operation.
This requires:
- team redundancy,
- cross-training,
- rescue/medical response,
- spare staffing.

### Long-horizon knowledge continuity
A fresh capture can restore rare expertise months later and reduce civilization-level permanent loss.

The current employment rule blurred the two.

**Decision**
The review rejects `capture = safety equipment` as an adequate justification for compulsory capture.

It still recognizes that refusal may increase long-horizon staffing/training requirements for some rare specialties.

**Result**
The dispute becomes measurable instead of ideological.

**Cost**
The program must fund more living redundancy rather than treating future restoration as cheap insurance.

**Theme**
TH-006 + TH-007.

**Reward / Hook**
RWD-FACT + RWD-COMP.

# EP208 — Refusal Does Not Mean Free Accommodation

**Immediate Goal**
Set a current legal/operational precedent from Daria's case without promising unlimited accommodations.

**Primary Engine**
E2/E7.

**Secondary**
E5.

**External State**
Daria's non-capture assignment is viable because a specific redundancy/cross-training package exists.

But the program cannot duplicate that package without limit for every specialized role in the first arrival cohorts.

**Decision / Precedent**
The current rule becomes:

- capture/restoration consent remains voluntary,
- refusal cannot itself reduce civic rank or ordinary employment standing,
- a specific scarce/high-risk assignment may impose **demonstrable present operational resilience requirements**,
- institutions must first examine feasible non-capture accommodations,
- if no adequate capacity exists, access to that particular assignment can be delayed/denied without treating refusal as wrongdoing.

**Result**
Daria's role proceeds under the cross-training model.

**Cost / Next Question**
The system now needs a fair method for deciding who receives scarce accommodation/redundancy capacity.

**Theme**
TH-006 + TH-007.

**Continuity**
CQ-17 principle established.

**Reward / Hook**
RWD-SOCIAL + RWD-CHOICE + RWD-CLOSURE.

# EP211 — A Floor, a Cap, and a Queue

**Immediate Goal**
Build an allocation rule that protects access without promising impossible universality.

**Primary Engine**
E7 Governance/Policy.

**Secondary**
E5/E2.

**External Event**
Selma/Tessa/Elin/labor/local representatives model alternatives.

**Decision / Working Rule**
The first-wave program adopts:

1. **common accessibility floor** — no category/provenance can be excluded wholesale,
2. **role-specific safety threshold** — real current task requirements remain,
3. **protected accommodation capacity** — some shared resources reserved so easiest bodies/preferences do not consume everything,
4. **transparent cap** — once true operational support capacity is exhausted, no false promise,
5. **equal-candidate selection** — where candidates are materially equivalent, rotation/lottery/transparent scheduling rather than wealth/status,
6. **appeal / later-cohort path** — delay is not permanent civil exclusion.

**Result**
A fair-but-finite system exists.

**Cost**
Nobody can claim every qualified person has an immediate right to every scarce assignment.

**Theme**
TH-007.

**Reward / Hook**
RWD-CHOICE + RWD-SOCIAL.
HK-PROMISE.

**4-point** 4/4.

# VI-B Rollup

## Consent payoff
A restored person can rationally defend restoration access and still refuse future capture/restoration for herself.

## Operational realism
Capture does not rescue today's operation; living redundancy still matters.
Refusal can increase long-horizon training/staffing cost without becoming wrongdoing.

## Fairness payoff
The story rejects both:
- `rights disappear when expensive`,
- `rights guarantee infinite scarce-role access`.

The system uses:
- common floor,
- actual role risk,
- protected accommodation capacity,
- transparent cap,
- fair selection,
- later-cohort path.

## Character
- Daria breaks faction stereotype
- Elin carries consent medicine independently
- Luca/H8 repair apprenticeship pays into destination resilience

## Handoff
The new staffing/accommodation architecture is incorporated into a large synchronized move whose physical model closes—but whose representation of lived dependencies remains incomplete.
