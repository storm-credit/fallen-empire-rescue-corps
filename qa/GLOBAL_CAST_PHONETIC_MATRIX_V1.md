# 3. Full-Name Rhythm Audit

Most names are deliberately short.

Potential rhythm families:
- 2+2: many core names
- 3+2: 다리아 토브 / 리비아 케스트 / 나디아 벨로
- 2+1/short: 키안 렐 / 사라 코르 / 니라 덴 / 페로 닐

The addition of faction/supporting names breaks the core's original 2+2 rhythm sameness enough for series-level use.

PASS.

# 4. Same-Surname Logic

Shared surname is currently intentional only where relationship clarity benefits:

### Savin
Haren / Mara / Yuna.

### Velo
Nadia / Lea.
