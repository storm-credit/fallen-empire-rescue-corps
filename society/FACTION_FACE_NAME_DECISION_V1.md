# Why Mira Den Changed

Previous candidate:
`미라 덴 / Mira Den`

Problem:
Core character `마라 사빈 / Mara Savin` creates an avoidable audio pair:

`마라 / 미라`.

Replacement:
**니라 덴 / Nira Den**.

Benefits:
- `니` is unused across current core/faction/support first syllables
- keeps short, Earth-derived/light-drift feel
- preserves the archivist's understated rather than symbolic naming
- practical web collision screening did not surface a major exact fictional-character conflict requiring rejection

No narrative meaning is attached to `Nira`.

# Naming Rule

Use these names in future design documents unless later global collision/IP review finds a concrete problem.

They are not yet immutable Canon Freeze because the entire supporting population has not been named, but these 10 recurring faces should no longer be renamed casually.
