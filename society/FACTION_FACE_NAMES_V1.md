# 1. Naming Goal

These names are designed as a **set**, not one by one.

They must:
- remain audibly distinct from the core cast
- remain audibly distinct from one another
- feel Earth-derived/lightly drifted rather than alien/fantasy
- avoid symbolic naming that announces ideology
- be short enough for Korean audio/TTS

Core-cast initials already occupied heavily:
하 / 마 / 유 / 테 / 엘 / 토 / 키 / 브 / 나.

Faction-face first syllables therefore deliberately spread elsewhere where practical.

- Cain/Abel

- mythic death gods
- famous political theorists

This is intentional.

Characters should not arrive pre-labeled by their author's theme.
